# Mood Journal

this is project number 10

# The idea of this project 

the user start to enter his mood and the date and some details of his day (optional) with maxlength 300 letter.

after submision it will appear down the history .

the submision button will disable if the user didn't enter the mood or the date or if he entered more than 300 letter.

if the user chose sad or angry from the options it will appear in the history with background color red .
